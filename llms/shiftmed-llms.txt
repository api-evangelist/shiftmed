# ShiftMed

> ShiftMed is a healthcare workforce technology company in McLean, Virginia. It runs an
> on-demand clinician marketplace and an AI-powered open shift management platform for
> hospitals, health systems, skilled nursing facilities and post-acute providers, matching
> credentialed W-2 CNAs, LPNs and RNs to open shifts. ShiftMed markets an API that lets a
> facility tap that clinician network from inside its own scheduling system, but publishes
> no developer portal, no reference documentation, no machine-readable specification and no
> SDK. This file is generated by API Evangelist from public sources; it is not published by
> ShiftMed.

## API surface

- [ShiftMed Workforce API](https://www.shiftmed.com/about/partners/): Marketed API for
  facilities to fill open shifts from ShiftMed's clinician network. Production host
  `https://api.shiftmed.com/v1` answers (`/v1/health` returns HTTP 200). No published
  specification, reference, authentication guide, or self-serve signup — access is arranged
  through a workforce consultation.
- Integration is also offered as file-based SFTP feeds alongside the API.

## Partner integrations (how the API is actually reached)

- [UKG Pro Workforce Management](https://www.shiftmed.com/press-releases/shiftmed-announces-technology-partnership-with-ukg/): API integration sharing shift and staff data with UKG Dimensions.
- [symplr Smart Square](https://www.shiftmed.com/press-releases/shiftmed-integrates-with-symplr-smart-square/): Approved open shifts route to the ShiftMed marketplace and confirmed shifts reconcile back into Smart Square.
- [QGenda](https://www.shiftmed.com/press-releases/shiftmed-announces-integration-with-qgenda/): Open shifts flow automatically between QGenda and ShiftMed.
- [Smartlinx](https://www.shiftmed.com/press-releases/shiftmed-and-smartlinx-partner/): Smartlinx Staffing Marketplace integration for long-term care.
- [Attendance on Demand](https://www.shiftmed.com/about/partners/): Contingent-pool access for nursing homes and long-term care.
- [Uber Health](https://www.shiftmed.com/press-releases/shiftmed-and-uber-health-launch-first-of-its-kind-partnership/): Transportation for clinicians travelling to shifts.
